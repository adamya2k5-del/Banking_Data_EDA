# Banking Data - Exploratory Data Analysis

## Objective
Exploratory analysis of banking campaign data to understand 
client demographics, behaviour patterns, and factors influencing 
term deposit subscription.

## What's covered
- Client demographic analysis (age, job, education, marital status)
- Financial behaviour (balance, loans, defaults)
- Campaign analysis (contact frequency, duration, outcomes)
- Correlation analysis between attributes and subscription likelihood

## Tools
Python, Pandas, Matplotlib, Seaborn
